# Music Listening Stats API — Mini Flask API + Logging + SQLite

## 1) Executive Summary

**Problem:** Provide a reproducible REST API that stores and serves music listening statistics (who listened to what and when) for demo, analytics, or coursework.  
**Solution:** A containerized Flask application exposing endpoints to list and record listens, backed by an embedded SQLite database and structured JSON logging for observability.

---

## 2) System Overview

**Course Concept(s):**
- Flask REST API (routing, request handling)
- Structured logging / observability
- Data persistence via SQLite
- Containerization with Docker
- Reproducible data seeding (CSV → DB)
